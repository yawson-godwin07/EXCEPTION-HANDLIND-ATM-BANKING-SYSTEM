# EXCEPTION-HANDLING-ATM-Banking-System

## Description
This repository contains a Python implementation of a simple Banking ATM System developed for the Week 8 Exception Handling Lab Session.

## Key Features & Exception Handling
- **`BankAccount` Class**: Manages deposits, withdrawals, and balance inquiries.
- **`InsufficientFundsError`**: Custom exception raised when a withdrawal exceeds the balance.
- **Input Validation**: Standard `ValueError` raised for negative deposits or invalid withdrawal amounts.

python main.py
